# Meridian

[![Status](https://img.shields.io/badge/status-early%20development-yellow)](https://github.com/pgala3183/Meridian)

**Meridian** is a production-grade long-form video intelligence platform: multi-provider AI,
chunked retrieval over hours of video, and the infrastructure to run it reliably at scale.
Inspired by open-source work in this space, rebuilt from the ground up under a new architecture
and name.
